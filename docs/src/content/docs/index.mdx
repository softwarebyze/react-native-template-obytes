## What this fork adds


- **Self-PR template sync** — generated apps watch this repo and open a PR on themselves. Never auto-merges. No central bot.
- Bleed-overlay store frames via screenshots compose, JSON-driven, no product-specific scenes.
- PostHog is disabled-safe; analytics is a no-op until you set a real project token.
- EAS metadata placeholders with valid generic categories. Push listing copy later; do not chain it after no-wait builds.
- Expo Router demo with onboarding, sample auth, and a sample feed so you delete screens instead of inventing them.
- CI that must go green: lint, type-check, Jest. Lockfile committed.

## Scaffold

Do not use create-obytes-app if you want these extras — that CLI always clones upstream obytes/react-native-template-obytes.

Clone softwarebyze/react-native-template-obytes, then read docs/template-sync.md.
